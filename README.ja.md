# TouchEngine — Android 片手操作支援システム

[中文](README.md) ｜ 日本語

Android のユーザー補助（アクセシビリティ）サービスを利用した片手操作支援アプリです。画面上のフローティングジョイスティックを親指で操作するだけで、指が届かない画面上部や反対側の端にあるボタンを選択・タップできます。

## 背景

スマートフォンの大画面化により、片手で持ったまま画面上部や遠い側のボタンを押すことが難しくなっています。既存の片手モードは画面全体を縮小・移動する方式が中心で、操作のたびに表示が変わります。本システムは画面表示を変えずに、手元のジョイスティックから操作対象を直接選択する方式を採用しています。

## 主な機能

- **フローティングジョイスティック**：親指の届く位置に置いたジョイスティックを倒す方向で、画面上の操作対象を順に選択します。
- **複数ソースによる操作対象の認識**
  - アクセシビリティツリー（アプリが公開している UI 情報）
  - YOLO による UI 要素検出（TensorFlow Lite、端末内で実行）
  - ML Kit による文字認識（OCR、端末内で実行）
- **ターゲット融合エンジン**：3 種類の認識結果の重複を除去し、アイコンと下のラベルを 1 つの対象にまとめます。
- **目標感染ナビゲーションアルゴリズム（ContagionNavEngine）**：ジョイスティックの方向と強さから、次に選ぶべき対象を決定します。同じ方向に倒し続けると選択が加速します。
- **緑色の枠**：現在選択されている対象を緑色の枠で表示します。

## 操作方法

| 操作 | 動作 |
| --- | --- |
| ジョイスティックをドラッグ | 倒した方向の操作対象を選択 |
| 指を離した後、ジョイスティックを 1 回タップ | 選択中の対象をタップ（確定） |
| 選択していない状態で 1 回タップ | 戻る |
| 2 回タップ | ホーム画面へ |
| 長押ししてからドラッグ | ジョイスティックの位置を移動 |

画面の端に置いたジョイスティックはしばらくすると半分隠れます。タップすると元に戻ります。

## 動作環境

- Android 7.0（API 24）以上
- 動作確認端末：Redmi K70 Ultra（HyperOS）ほか
- 主な確認アプリ：WeChat、淘宝（Taobao）、抖音（Douyin）

YOLO の推論時間は Redmi K70 Ultra（NNAPI 使用）で約 120〜155ms です。

## ビルド方法

1. GitHub の **Code** → **Download ZIP**、または Git でリポジトリをクローンします。
2. Android Studio でプロジェクトのルートフォルダを開きます。
3. Gradle の同期が終わったら、Android 端末を接続するかエミュレーターを起動し、`app` を実行します。

Gradle Wrapper を使用しているため、Gradle を別途インストールする必要はありません。初回の同期では Android / Gradle の依存ライブラリをダウンロードするため、インターネット接続が必要です。

## 初回設定（ユーザー補助の有効化）

1. アプリを起動し、「ユーザー補助の設定を開く」を押します。
2. 端末の設定画面で「ダウンロードしたアプリ」「インストール済みサービス」などの一覧から本アプリを探します（項目名は端末によって異なります）。
3. サービスをオンにし、システムの説明を確認して許可します。
4. アプリに戻り、「ユーザー補助は有効です」と表示されたら、サービススイッチをオンにします。

Android 13 以降の一部の端末では、APK からインストールしたアプリのユーザー補助設定が制限され、スイッチが灰色になることがあります。その場合はアプリの「アプリ情報」を開き、右上のメニューから「制限付き設定を許可」を選んでから、もう一度設定してください。

## モデルファイル

UI 検出モデルはリポジトリに含まれています。

`app/src/main/assets/yolo/ui-detector-fp32-960.tflite`

ラベルファイルとサンプル画像も同梱しているため、リポジトリをダウンロードすればそのままビルドできます。

## プライバシー

本アプリは画面上の操作対象を認識するために、ユーザー補助の権限で画面の内容を読み取ります。画面の認識（YOLO・OCR）はすべて端末内で処理されます。
